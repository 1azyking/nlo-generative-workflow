# Paper datasets

Archive: https://doi.org/10.6084/m9.figshare.31849795.v2

| Archive directory or file | Contents |
|---|---|
| datasets_CDVAE/oxygen-containing/ | Five datasets: BCN_40, BP_40, CSi_40, NP_40, and SiPS_30; each has train.csv, val.csv, and test.csv |
| datasets_CDVAE/oxygen-excluded/ | Six datasets: S_20, PS_20, AsSe_20, SbTe_20, PAsSb_20, and SSeTe_20; each has train.csv, val.csv, and test.csv |
| datasets_LGBM/ | dataset_dij.csv and dataset_dn.csv, containing property labels and compositional/structural features |
| generated_structures/ | Eleven sets of CDVAE outputs in *_gen.pt files |
| calculations.zip | VASP inputs and outputs, and optical property results for candidate materials |

Preserve the archive's directory hierarchy so that files with the same name, such as train.csv, remain associated with their datasets.
See [models/README.md](../models/README.md) for trained models.
